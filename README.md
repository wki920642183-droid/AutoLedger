# 自动记账本 App —— 使用与编译教程（小白版）

## 这是什么
一个**安卓手机 App**：你在微信里付一笔钱，手机通知栏弹出“微信支付”通知的瞬间，它就会自动把**金额、付款对象、分类**记到账本里，数据**全部存在你手机本地，不上传任何服务器**。

本教程只做一件事：带你把这套代码**免费编译成一个能装的安装包（APK）**，然后在手机上用起来。全程不用装任何开发软件。

---

## 隐私说明（很重要）
- 所有账目只存在手机本地的 SQLite 数据库里。
- App **不会**联网、不会上传你的任何数据。
- 它只读取“微信支付”这一种通知的文字内容，用来记账。

---

## 你需要准备
1. 一部 **安卓手机（Android 8.0 及以上，现在基本都符合）**
2. 一个**免费的 GitHub 账号**（只用来帮你编译，不用懂代码）
3. 一台能上网的电脑（或手机浏览器也行），用来上传文件

> GitHub 是什么？一个免费的代码托管网站（github.com）。我们只用它“自动编译”这一个功能。

---

## 第一步：注册 GitHub（已有账号可跳过）
1. 打开 https://github.com
2. 点右上角 **Sign up（注册）**
3. 按提示填邮箱、设密码、用户名，验证邮箱即可。
   全程网页操作，和注册普通网站一样。

---

## 第二步：新建一个仓库（Repository）
1. 登录后，点页面右上角 **“+” → New repository（新建仓库）**
2. Repository name（仓库名）填：`AutoLedger`
3. 下面选 **Public（公开）** 或 **Private（私有）** 都可以
4. **不要**勾选 “Add a README file” 等任何初始化选项（保持全空）
5. 点 **Create repository（创建仓库）**

创建后会进入一个空仓库页面，记住它。

---

## 第三步：把本项目文件上传到仓库
本项目所有文件已经在你电脑的这个文件夹里：

```
C:/Users/Administrator/WorkBuddy/2026-11-09-15-11-51/AutoLedger/
```

你需要把这个文件夹里的**全部内容**（包括 `app/`、`gradle/`、`settings.gradle`、`.github/` 等）上传到刚才建的仓库。

### 方法 A：网页直接拖拽（推荐先试）
1. 在 GitHub 仓库页面，点 **“uploading an existing file”** 或 **Add file → Upload files**
2. 打开你电脑上的 `AutoLedger` 文件夹
3. 选中文件夹里的**所有内容**（按 Ctrl+A），直接**拖到网页上传区**
   - GitHub 会自动保留 `app/`、`gradle/`、`.github/` 等子文件夹结构
4. 拖完后，页面底部填一句说明（如 `init`），点 **Commit changes**

> 如果网页拖拽报错或卡住（偶尔会因为文件多而失败），改用下面的方法 B。

### 方法 B：用 GitHub Desktop（图形界面，更稳定）
1. 下载安装 GitHub Desktop：https://desktop.github.com/
2. 登录你的 GitHub 账号
3. File → Clone repository，选中你刚建的 `AutoLedger` 仓库，克隆到电脑
4. 把 `AutoLedger` 文件夹里的**全部内容**复制进克隆出来的那个文件夹
5. 在 GitHub Desktop 里会看到一堆新文件，点 **Commit to main**，再点 **Push origin**
6. 上传完成

---

## 第四步：等它自动编译（约 3–8 分钟）
文件一进仓库，GitHub 就会**自动开始编译**，不用你点别的东西。

查看进度：
1. 进入你的仓库页面
2. 点上方 **Actions（动作）** 标签
3. 你会看到一条正在跑的任务（黄点 = 进行中）
4. 等它变成 **绿色对勾 ✅** 就成功了
   - 如果显示 **红色叉 ❌**，见文末“编译失败怎么办”

---

## 第五步：下载安装包（APK）
1. 在 Actions 页面点进那条成功的任务
2. 页面下方 **Artifacts（产物）** 区域，点 **AutoLedger-APK** 下载
3. 得到一个 zip，解压后得到 **`app-debug.apk`**

---

## 第六步：在手机上安装
1. 把 `app-debug.apk` 传到手机（微信发自己、U盘、网盘都行）
2. 在手机文件管理器里点它，会提示“允许安装未知来源应用”
3. 按提示**允许**（不同手机路径：设置 → 安全/隐私 → 安装未知应用 → 允许对应来源）
4. 完成安装，桌面上出现 **“自动记账本”** 图标

---

## 第七步：开启“通知监听”权限（关键！否则不会记账）
1. 打开 App → 点右上角 **设置**
2. 看“通知监听权限”那一行，如果是 **未开启 ✗**
3. 点 **“去开启通知监听权限”**，会跳到系统设置
4. 在列表里找到 **“自动记账本”**，把开关打开
5. 返回 App，状态应变成 **已开启 ✓**

> 这是安卓系统的安全机制：只有你手动授权，App 才能读取通知。

**再确认微信通知是开的**：微信 → 我 → 设置 → 新消息通知 → 打开；并确认“微信支付”通知会出现在通知栏（别开“通知免打扰”把支付通知屏蔽了）。

---

## 怎么用
- **微信付一笔钱** → 通知栏刚弹出“微信支付”的瞬间，App 就自动记一笔（顶部会弹一条“已自动记账”的轻提示）。
- 打开 App 首页：看**本月支出/收入**、**分类占比**、**每笔明细**。
- 点某条记录：可**改分类**或**删除**。
- 设置里可以：**关闭记账提示通知**、**清空账单**、看**关于**。
- 首页点 **导出**：把账单导出成 CSV 文件，可用 Excel / WPS 打开。

---

## 微信付了钱却没自动记？逐项排查
1. **通知监听权限开了吗？** 设置里看是不是“已开启 ✓”。
2. **微信支付通知真的弹出来了吗？** 付钱时看一眼通知栏有没有“微信支付”通知；没有就去微信设置里打开新消息通知。
3. **App 有没有被后台杀掉？** 小米/华为/OPPO/vivo 等手机管得严，去手机“自启动管理 / 电池优化 / 应用锁”里，把“自动记账本”设为**允许自启动、不限制后台**。
4. **金额识别对了吗？** 微信通知的文字格式偶尔会变，若商户名识别不准，点该条记录手动改分类即可。

---

## 进阶：以后想重新编译 / 改分类
- **重新编译**：改完仓库里的文件，Commit 后 GitHub 会自动重新编译，去 Actions 下载新的 APK 即可。
- **改分类规则**：打开 `app/src/main/java/com/autoledger/app/CategoryRules.kt`，在对应分类的词语列表里加关键词（如 `"奶茶"`、`"滴滴"`），保存上传即可。

---

## 编译失败（Actions 红叉）怎么办
1. 点进失败的任务，看红色报错日志。
2. 最常见原因：GitHub 网页上传时**漏了文件或子文件夹**（尤其 `.github/` 文件夹容易漏）。
   - 解决：确认仓库里有 `app/`、`gradle/`、`settings.gradle`、`build.gradle`、`.github/workflows/build.yml` 这些都在，缺哪个补传哪个，重新 Commit 即自动重编。
3. 仍不行：把红色报错文字发给我，我帮你定位。

```

├─ .github/workflows/build.yml   # 自动编译脚本（CI）
├─ app/
│  ├─ build.gradle               # App 编译配置
│  └─ src/main/
│     ├─ AndroidManifest.xml     # 权限与服务声明
│     ├─ java/.../app/
│     │  ├─ MainActivity.kt          # 首页：汇总/列表/导出
│     │  ├─ SettingsActivity.kt       # 设置：权限引导/清空
│     │  ├─ TransactionService.kt     # 通知监听 + 微信支付解析（核心）
│     │  ├─ DatabaseHelper.kt         # 本地账本数据库
│     │  ├─ CategoryRules.kt          # 分类规则
│     │  ├─ TransactionAdapter.kt     # 列表适配器
│     │  ├─ Transaction.kt            # 账目数据模型
│     │  └─ Prefs.kt                  # 偏好设置
│     └─ res/                       # 界面布局与图标
├─ build.gradle / settings.gradle / gradle.properties  # 工程配置

```
